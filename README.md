# FlashX

FlashX is a simple, fast, and powerful flashcard creation web browser extension.

## Features

- Create flashcards from any website just by higlighting the text you want to save.
- Save flashcards.
  Hand Gesture Feedback – “Talk to the Hand”
- Use the webcam and a hand pose detection model to register user feedback on flashcards.
  - For example:
  - Thumbs up → “Easy”
  - Thumbs down → “Hard”
  - Flat palm → “Didn’t know”
